# Sounds of Reema: concept prototype

A concept redesign of DJ Reema's website, built as a working, responsive prototype by Ikedi J. Nwogu.
Her live site is [soundsofreema.com](https://soundsofreema.com/).

- Case study: https://www.ijnwogu.com/projects/reema.html
- Prototype: `index.html` (plain HTML and CSS, no build step), with photos in `photos/`

The page is marked `noindex` so it doesn't compete with her live site in search.
